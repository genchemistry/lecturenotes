The block shows which type of orbital is being filled as electrons are added across that region of the periodic table.

Main-group elements

The last electron added enters an outermost s or p orbital.

For main-group elements, the valence electrons are the electrons in the highest n level.

Transition elements

The d block corresponds to filling an (n−1)d subshell.

Transition-element valence electrons can include both ns and (n−1)d electrons.

Helium: He is placed in Group 18 because of its chemical behavior, but its electron configuration is 1s². In an electron-configuration block map, He belongs to the s block.

So block position tells us the orbital type being filled; it does not mean that every valence electron of every element is located in that one block.

Why Can the Aufbau Prediction Differ?

Learning Objective: Connect anomalous ground-state configurations to the fact that sublevel energies in multi-electron atoms depend on several competing electron–nucleus and electron–electron effects.
In multi-electron atoms, orbital energies depend on more than the principal quantum number.
+ ↔ −

Nucleus–electron attraction

Electrons are attracted to the positively charged nucleus.

− ↔ −

Electron–electron repulsion

Electrons repel one another, so electron arrangement affects energy.

s > p > d > f

Shielding and penetration

Different orbitals experience nuclear attraction differently.

Key idea: the ns and (n−1)d sublevels can be close in energy. Small differences in attraction, shielding, penetration, and electron–electron repulsion can change which arrangement has the lowest energy.

Inner, Outer, and Valence Electrons

Learning Objective: Distinguish outer, valence, and inner/core electrons by location and function, then identify each category from main-group and transition-element configurations.

Outer electrons

WHERE? → highest n
  • Find the largest n in the electron configuration.
  • Count all electrons with that n: ns and, if present, np.
[Ar] 4s² 3d⁶ → highest n = 4 → 2 outer e⁻

Valence electrons

FUNCTION? → bonding
  • Electrons involved in forming compounds / chemical bonds.
  • Main group: valence e⁻ = outer e⁻.
  • Transition: valence e⁻ can include ns + (n−1)d.
Important later → Lewis dot structures

Inner (core) electrons

WHAT IS LEFT? → not valence
  • Electrons not counted as valence electrons.
  • For a neutral atom, total e⁻ = Z.
inner e⁻ = Z − valence e⁻
Transition elements: do not substitute outer e⁻ for valence e⁻.

Electron Configurations of Ions

Learning Objective: Use the highest-n rule to identify which electrons are removed first when main-group and transition-metal cations form.
Rule of thumb for forming cations
1. Find the highest occupied n
Those are the outer electrons.
→
2. Remove electrons from that outer level first
Main group: np before ns when both are occupied.
Transition metals: ns before (n−1)d.

Main-group example — Al → Al³⁺

Al: [Ne] 3s² 3p¹

highest n = 3 → outer valence electrons are 3s² 3p¹

[Ne] 3s² 3p¹→[Ne] 3s²
[Ne] 3s²→[Ne]
Al³⁺ = [Ne]

Transition example — Fe → Fe³⁺

Fe: [Ar] 4s² 3d⁶

highest n = 4 → remove 4s before 3d

[Ar] 4s² 3d⁶→[Ar] 3d⁶
[Ar] 3d⁶− 1 e⁻[Ar] 3d⁵
Fe³⁺ = [Ar] 3d⁵

Anomalous neutral configuration — Cu → Cu⁺

Cu: [Ar] 4s¹ 3d¹⁰

highest n = 4 → remove the 4s electron first

[Ar] 4s¹ 3d¹⁰ → [Ar] 3d¹⁰
Cu⁺ = [Ar] 3d¹⁰

Filled 4f subshell remains core — Au → Au³⁺

Au: [Xe] 6s¹ 4f¹⁴ 5d¹⁰

highest n = 6 → remove 6s first, then remove from 5d. 4f¹⁴ remains filled.

[Xe] 6s¹ 4f¹⁴ 5d¹⁰ → [Xe] 4f¹⁴ 5d¹⁰
[Xe] 4f¹⁴ 5d¹⁰ − 2 e⁻ from 5d [Xe] 4f¹⁴ 5d⁸
Au³⁺ = [Xe] 4f¹⁴ 5d⁸
Keep the two ideas separate: Electron filling order and electron-removal order are not the same statement. For transition-metal cations, the course rule is remove ns before (n−1)d.

Learning Objective: Use orbital occupancy to determine whether an atom or ion is paramagnetic or diamagnetic.

Paramagnetic

Contains one or more unpaired electrons.

Challenging
