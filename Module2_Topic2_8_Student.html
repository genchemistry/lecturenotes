Hydrate

Ionic compound · fixed number of H₂O molecules.

A formula that contains H is not automatically an acid. Context and formula pattern matter.

Recognizing Acids

Learning Objective: Distinguish acid formulas from other hydrogen-containing compounds.

Binary acid

H + one nonmetal; no oxygen in the anion.

HCl(aq), HBr(aq)

Oxyacid

H + an oxygen-containing polyatomic anion.

HNO₃(aq), H₂SO₄(aq)

Compare: HCl(g) is hydrogen chloride; HCl(aq) is hydrochloric acid.

The naming pathway depends on the anion: monatomic anion → binary acid; oxyanion → oxyacid.

Common Bases

Many common bases in this course are ionic compounds containing the hydroxide ion, OH⁻.

Hydrates

Learning Objective: Name hydrates using the ionic compound name followed by a water-count prefix + hydrate.
ionic compound name+prefix for H₂O count+hydrate
CuSO₄·5H₂O

CuSO₄ = copper(II) sulfate; 5 H₂O = penta + hydrate

copper(II) sulfate pentahydrate
Ca(OH)₂·4H₂O
calcium hydroxide tetrahydrate

The prefix here counts water molecules; it does not change the ionic naming of the salt portion.
