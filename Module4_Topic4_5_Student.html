The Sum Rule — Start Simple, Then Add Charge

Learning Objective: Find an unknown oxidation number by making the oxidation-number sum equal the overall charge.
Neutral compound
The sum of all oxidation numbers = 0
Polyatomic ion
The sum of all oxidation numbers = the ion charge
Strategy: write the formula as an oxidation-number equation, substitute the values you already know, then solve the unknown.

Example 1 — PF₅ (neutral compound)

PF₅
P + 5F = 0
P + 5(−1) = 0
P = +5
Therefore, P = +5 and F = −1.

Example 2 — HCO₃⁻ (polyatomic ion)

HCO₃⁻
H + C + 3O = −1
(+1) + C + 3(−2) = −1
C = +4
Therefore, H = +1, C = +4, and O = −2.

Two Ways to Track a Redox Reaction

Learning Objective: Connect electron movement and oxidation numbers (O.N.) using the same reaction.

Method 1 — Follow the electrons directly

2Mg + O₂ → 2MgO

Reactants

[Mg]
2Mg
[O]
O₂ + 4e⁻

Products / Electron change

[Mg]
2Mg²⁺ + 4e⁻
Each Mg loses 2e⁻.
electron loss → oxidized
[O]
2O²⁻
Each O atom gains 2e⁻; O₂ gains 4e⁻ total.
electron gain → reduced

Method 2 — Follow the oxidation numbers (O.N.)

2Mg + O₂ → 2MgO
First find the oxidation numbers in MgO.

Reactants

[Mg]
Mg in elemental Mg: 0
[O]
O in elemental O₂: 0

Products

Mg + O = 0
Mg + (−2) = 0
Mg = +2
[Mg]
0 → +2
O.N. increases → loses e⁻ → oxidized
[O]
0 → −2
O.N. decreases → gains e⁻ → reduced
O.N. increases loses e⁻ → oxidized → reducing agent
O.N. decreases gains e⁻ → reduced → oxidizing agent
If one species is oxidized, another species must be reduced — electrons are transferred, not created or destroyed.
For 2Mg + O₂ → 2MgO: Mg is oxidized → reducing agent. O₂ is reduced → oxidizing agent.

Worked Redox Example — Zn + CuSO₄

Learning Objective: Use Method 2 — oxidation-number change — on a familiar metal-displacement reaction.

Step 1 — Write the reaction and assign oxidation numbers (O.N.)

Zn(s) + CuSO₄(aq) → ZnSO₄(aq) + Cu(s)

Reactants

Elemental Zn = 0
Cu in CuSO₄ = +2
S in SO₄²⁻ = +6, O = −2

Products

Zn in ZnSO₄ = +2
Elemental Cu = 0
S in SO₄²⁻ = +6, O = −2

Step 2 — Compare before and after

Zn: 0 → +2 → O.N. increases → loses e⁻ → oxidized
Cu: +2 → 0 → O.N. decreases → gains e⁻ → reduced
S: +6 → +6 and O: −2 → −2 → no redox change
Zn is oxidized → reducing agent.
Cu²⁺ in CuSO₄ is reduced → oxidizing agent.
One O.N. increases and another decreases → redox confirmed.

Worked Redox Example — Fe₂O₃ + C

Learning Objective: Use Method 2 to assign oxidation numbers, identify what changes, and name the agents.

Step 1 — Assign oxidation numbers (O.N.)

2Fe₂O₃(s) + 3C(s) → 4Fe(s) + 3CO₂(g)

Reactants

In Fe₂O₃: O = −2
2Fe + 3(−2) = 0
2Fe − 6 = 0
Fe = +3
Elemental C = 0

Products

Elemental Fe = 0
In CO₂: C + 2(−2) = 0
C − 4 = 0
C = +4
O remains −2

Step 2 — Compare before and after

Fe: +3 → 0 → O.N. decreases → gains e⁻ → reduced
C: 0 → +4 → O.N. increases → loses e⁻ → oxidized
O: −2 → −2 → no redox change
Fe₂O₃ contains Fe³⁺ that is reduced → oxidizing agent.
C is oxidized → reducing agent.
One O.N. decreased and another increased → redox confirmed.

Three Displacement Redox Patterns to Recognize

Learning Objective: Recognize three common displacement redox patterns from the reactants and products.
Important: These are three common displacement redox patterns — not the only kinds of redox reactions.

Metal displacement

A free metal replaces another metal ion in a compound.

Fe(s) + CuSO₄(aq) → FeSO₄(aq) + Cu(s)

Halogen displacement

A free halogen replaces a halide ion.

Cl₂(g) + 2NaBr(aq) → 2NaCl(aq) + Br₂(g)

Hydrogen displacement

An active metal reacts with an acid and displaces H⁺, producing H₂(g).

Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g)
Metal displacement Free metal + compound containing another metal ion.
Halogen displacement Free halogen + compound containing a halide ion.
Hydrogen displacement Active metal + acid → H₂(g).
Verification step: pattern recognition is only the first pass. Confirm redox by finding one oxidation number that increases and another that decreases.

Disproportionation — One Element Is Both Oxidized and Reduced

Learning Objective: Track every element carefully and identify when the same element experiences both oxidation and reduction.

Example 1 — Hydrogen peroxide

2H₂O₂(aq) → 2H₂O(l) + O₂(g)
Before reaction: in H₂O₂, H = +1, so O = −1.
After reaction: in H₂O, H = +1 and O = −2.
After reaction: in O₂, elemental O = 0.

One oxygen pathway

O in H₂O₂: −1 → O in H₂O: −2
O.N. decreases → gains e⁻ → reduced

Another oxygen pathway

O in H₂O₂: −1 → O in O₂: 0
O.N. increases → loses e⁻ → oxidized
Hydrogen check: H in H₂O₂ is +1 and H in H₂O is still +1. Hydrogen is neither oxidized nor reduced.
The same element, oxygen, is both oxidized and reduced → disproportionation.

Second pattern check — chlorine in base

Cl₂(g) + 2NaOH(aq) → NaCl(aq) + NaClO(aq) + H₂O(l)
Cl: 0 → −1
O.N. decreases → reduced
Cl: 0 → +1
O.N. increases → oxidized
Conclusion: the same chlorine starts at 0 and ends at two different oxidation numbers, so chlorine is both reduced and oxidized.

Is It Redox? — Reaction-Type Diagnosis

Learning Objective: Distinguish redox from nonredox reactions by checking oxidation-number changes.

Combustion

CH₄ + 2O₂ → CO₂ + 2H₂O
Redox

Metal displacement

Fe + CuSO₄ → FeSO₄ + Cu
Redox

Precipitation

2KI + Pb(NO₃)₂ → PbI₂ + 2KNO₃
No oxidation-number change
A double-displacement reaction.

Neutralization

HCl + NaOH → H₂O + NaCl
No oxidation-number change
A double-displacement reaction.
Best test: redox requires one oxidation number to increase and another to decrease.
Pattern is not enough: precipitation and neutralization are commonly double-displacement reactions, but they are not redox when oxidation numbers do not change.
