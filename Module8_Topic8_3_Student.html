Atomic Radius — Big Picture

Learning Objective: Use shell number and Effective Nuclear Charge, Zeff, to predict the general trend in atomic radius.
Atomic size is controlled by two competing ideas: more occupied shells make atoms larger, while larger Zeff pulls electrons closer.

Shell-number idea

If the outer electrons are in a higher principal energy level, the atom is generally larger.

Zeff idea

If the outer electrons feel stronger attraction to the nucleus, the atom is generally smaller.

Prediction: Across a period, shell number stays the same while Zeff increases → atomic radius generally decreases. Down a group, additional shells dominate → atomic radius generally increases.

Cations vs Parent Atoms

Learning Objective: Explain why a cation is smaller than its parent atom.

Neutral Li

Li

152 pm

Li⁺ Cation

Li⁺

78 pm

When Li forms Li⁺, the ion has often less electron–electron repulsion and sometimes loss of an outer shell. That makes the cation smaller.
General rule: a cation is smaller than its parent atom.

Isoelectronic Series — Why the Sizes Differ

Learning Objective: Use proton number to compare the radii of isoelectronic species.

Isoelectronic series

Here, S²⁻, Ar, and Ca²⁺ each have 18 electrons.

So the key difference is proton number.

Largest

S²⁻

Fewer protons for the same 18 e⁻ → weaker attraction to the electron cloud → size up.

Middle

Ar

Intermediate proton number for the same 18 e⁻ → intermediate size.

Smallest

Ca²⁺

More protons for the same 18 e⁻ → stronger attraction to the electron cloud → size down.

Same electron count: more protons → smaller radius.

Worked Problem — Isoelectronic Ions

Learning Objective: Solve a multi-species ionic-radius ranking problem using isoelectronic reasoning.

Worked problem

Rank the following from largest → smallest:

O²⁻, F⁻, Na⁺, Mg²⁺

All four species have 10 electrons. So this is an isoelectronic comparison.

Key idea

Same electron count → compare proton number.

Protons: O = 8, F = 9, Na = 11, Mg = 12

Interpretation

Fewer protons → weaker attraction → larger radius.

More protons → stronger attraction → smaller radius.

O²⁻ > F⁻ > Na⁺ > Mg²⁺
Worked-problem pattern: identify isoelectronic species → compare proton number → rank.
