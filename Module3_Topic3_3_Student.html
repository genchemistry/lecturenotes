What Coefficients Mean — Particles, Moles, Not Grams

Learning Objective: Interpret coefficients as particle and mole ratios, not equal gram ratios.
2Mg(s) + O₂(g) → 2MgO(s)

Particle Reading

2 Mg atoms + 1 O₂ molecule → 2 MgO formula units

Mole Reading

2 mol Mg + 1 mol O₂ → 2 mol MgO

Mass Reading

48.6 g Mg + 32.0 g O₂ → 80.6 g MgO

Common wrong idea: 2 g Mg + 1 g O₂ does not mean 2 g MgO. Coefficients are not gram ratios.

Balancing Workflow — One Small Decision at a Time

Learning Objective: Balance equations using atom ledgers and coefficients without changing formulas.
1. Correct formulas

Do not invent products.

2. Count atoms

Make a left/right ledger.

3. Change coefficients

Only numbers in front.

4. Recount

Check every element.

5. Simplify

Smallest whole numbers.

Start easy

Balance an element that appears once on each side.

Groups help

If a polyatomic ion stays intact, count it as a group.

Save O and H

Especially in combustion, oxygen is often last.

Allowed

2H₂O means two water molecules.

Not Allowed

H₂O₂ is a different substance.

Balancing changes amount, not identity.

Balancing Example 1 — H₂ + Cl₂ → HCl

Learning Objective: Balance a simple equation by counting atoms, changing coefficients, and checking each element in sequence.
Worked · Step 1
H₂ + Cl₂ → HCl
Start by counting atoms. Both H₂ and Cl₂ are diatomic, so there are 2 H atoms and 2 Cl atoms on the left, but only 1 H and 1 Cl in one HCl on the right.
ElementLeftRight
H21
Cl21
1
Balance H first
There are 2 H atoms on the left and 1 H on the right, so place 2 before HCl.
2
Check Cl next
Now 2HCl contains 2 Cl atoms, so chlorine is automatically balanced.
3
Final check
H = 2 on both sides and Cl = 2 on both sides.
H₂ + Cl₂ → 2HCl
Why this works: changing the coefficient in front of HCl multiplies both H and Cl in that formula. We never change the subscripts.
Final balanced equation: H₂ + Cl₂ → 2HCl

Balancing Example 2 — Fe + O₂ → Fe₂O₃

Learning Objective: Use a temporary fractional coefficient to balance oxygen, then clear the fraction to obtain whole-number coefficients.
Worked · Choose the easier element
Fe + O₂ → Fe₂O₃
Usually, Fe would be a reasonable element to balance first because it appears once on each side. But in this equation, oxygen is easier: Fe₂O₃ contains 3 O atoms, while O₂ supplies oxygen in pairs. A temporary fraction lets us match those 3 O atoms immediately.
1
Count first
Fe: 1 → 2
O: 2 → 3
2
Choose O first
Match the 3 O atoms in Fe₂O₃ using a temporary coefficient on O₂.
3
Then finish
Balance Fe, then clear the fraction.
2
Balance O first

Keep Fe₂O₃ at 1. To get 3 O atoms from O₂, use 32 O₂.

Fe + 32 O₂ → Fe₂O₃
1
Now balance Fe

Fe₂O₃ contains 2 Fe atoms, so place 2 before Fe.

2 Fe + 32 O₂ → Fe₂O₃
3
Clear the fraction

Multiply every coefficient in the entire equation by 2 — not only the 3/2.

2 × ( 2 Fe + 32 O₂ → Fe₂O₃ )
4 Fe + 3 O₂ → 2 Fe₂O₃

Fe Check

4 Fe atoms on both sides

O Check

6 O atoms on both sides

Balancing Example 3 — Combustion: C → H → O

Learning Objective: Balance a hydrocarbon combustion equation in the order C → H → O, then clear a fractional O₂ coefficient when needed.
Hard · Combustion Strategy
C₂H₆+O₂→CO₂+H₂O
1. Balance C

2 C → place 2 before CO₂

2. Balance H

6 H → place 3 before H₂O

3. Save O for last

O₂ is diatomic, so divide total O atoms by 2

C₂H₆+O₂→ 2CO₂+3H₂O
Product-side O atoms: 2CO₂ gives 4 O + 3H₂O gives 3 O = 7 O atoms
O₂ coefficient: 7 O atoms2 O atoms per O₂ = 72 O₂.
C₂H₆+72O₂→ 2CO₂+3H₂O
If a fraction appears, multiply every coefficient by 2.
2C₂H₆+7O₂→4CO₂+6H₂O

Combustion Practice + Final Balance Check

Learning Objective: Apply C → H → O and verify the smallest whole-number coefficients without changing formulas
Guided Practice · Combustion
Pause: Balance C first, H second, and O last.
CH₄+O₂→CO₂+H₂O
CH₄ + 2O₂ → CO₂ + 2H₂O

Final check: C = 1, H = 4, O = 4 on both sides.

Fast check after balancing: no formula changed; all atom counts match; coefficients are whole numbers and reduced.
Changing H₂O to H₂O₂ or CO₂ to CO changes chemical identity and is never a balancing move.

Stoichiometry Setup Diagnosis — Common Errors

Learning Objective: Diagnose incorrect stoichiometric pathways, mole-ratio orientation, and molar-mass factors
ACS-Style
For 2H₂ + O₂ → 2H₂O, a student starts with 5.00 mol H₂ and wants mol O₂. Which mole-ratio factor has the correct orientation?
A. 2 mol H₂1 mol O₂
B. 1 mol O₂2 mol H₂
C. 18.02 g H₂O1 mol H₂O
D. 2 mol H₂O1 mol O₂
5.00 mol H₂ × 1 mol O₂2 mol H₂
The given unit mol H₂ must cancel.
Final checklist: balance first → convert given amount to moles → use coefficient ratio → convert out of moles only if needed. A factor is correct only if the unwanted unit cancels.
